01
Edita

Cambia textos, logos, fotografías y el catálogo desde las pestañas de este editor. Puedes guardar un borrador sólo en este navegador.

02
Descarga el archivo

Usa el botón azul Descargar contenido.js. Ese archivo incluye tus cambios y las fotos comprimidas que hayas cargado.

03
Publica en GitHub

Entra a tu repositorio emac-web- ↗, sube el nuevo contenido.js en la misma carpeta que index.html y confirma Commit changes. Si el archivo no puede sustituirse, consulta las instrucciones incluidas en el ZIP.

04
Espera a GitHub Pages

Tras el despliegue, la web pública mostrará los cambios. No debes subir otra vez index.html para editar sólo contenido.

Respaldo y recuperación

El borrador se guarda únicamente en tu navegador. Importar sirve para editar una copia descargada de GitHub. No se transmiten datos a terceros desde este editor.
